## 1. reg_a_017（监管 / 多选）— 优先级 88

### 题干

关于上市公司治理规范及行政处罚时效的相关规定，下列说法中正确的有哪些？

### 选项

| 选项 | 内容 |
|---|---|
| A | 上市公司章程及与治理相关的文件应当符合本准则的要求 |
| B | 董事候选人的相关信息应当在股东会召开之前予以披露 |
| C | 若信息披露违法不存在连续继续状态，则该信息已超过处罚时效 |
| D | 现金分红必须在年度审计报告出具前完成支付 |

### 原文定位

| 选项 | 文档 | 位置 | 关键原文 |
|---|---|---|---|
| A | `csrc_0023_att1` | 第 1 页 / 第二条 | 「上市公司章程及与治理相关的文件，应当符合本准则的要求。」 |
| B | `csrc_0023_att1` | 第 5 页 / 第十九条 | 「上市公司应当在股东会召开前披露董事候选人的详细资料」 |
| C | `csrc_0262` | 当事人申辩意见 | 「不存在连续继续状态，该信息已超过处罚时效」——**当事人辩护，非法规条文** |
| D | — | 无 | 给定文档中无「审计报告出具前必须支付分红」的规定 |

### 分歧点

- **DeepSeek 选 C**：将当事人申辩意见当作「处罚时效一般规定」的佐证，并用常识补全
- **Qwen verify 排除 C**：正确识别 C 仅为 `csrc_0262` 行政处罚决定书中的**申辩意见**，不能作为「相关规定」的正确表述

### 核对步骤

1. 打开 `processed_data/regulatory/csrc_0262.jsonl`，搜索「不存在连续继续状态」
2. 确认该句出现在「当事人提出以下申辩意见」段落，而非「本院认为」或法规引用
3. 核对 A、B 是否在 `csrc_0023_att1` 中有直接法条对应（有）
4. 核对 D 是否在任一给定文档中有依据（无）

### 建议结论

**gold = AB**（倾向 Qwen verify，置信度高）

## 2. res_a_006（研报 / 判断）— 优先级 87

### 题干

判断以下陈述是否正确：

> 2008 年至 2025 年前三季度，我国上市券商**客户资金杠杆**从 1.56 倍提升至 4.09 倍，同期自有资产净利率由 4.3% 降至 1.8%。

### 选项

A = 正确　｜　B = 错误

### 原文定位

文档：`pack2_text10`（东方财富证券《扩表：券商加杠杆路径探析》）

| 位置 | 关键原文 |
|---|---|
| 第 1 页 | 「2008年至2025Q1-3我国上市券商**除客户资金杠杆**从 1.56 倍稳步提升至 4.09 倍，而同期自有资产净利率由 4.3%降至 1.8%。」 |
| 第 6–7 页 | 改良杜邦模型专门区分「除客户资金杠杆」与传统「客户资金杠杆」，后者因含客户资金存款而失真 |

### 分歧点

- **DeepSeek 选 A**：数字与原文一致，未注意指标名称差异
- **Qwen verify 选 B**：题干写「客户资金杠杆」，原文为「**除**客户资金杠杆」——这是两个不同指标

### 核对步骤

1. 在 `processed_data/research/pack2_text10.jsonl` 搜索「1.56」和「除客户资金杠杆」
2. 阅读第 6 页改良杜邦分析表，理解「除客户资金杠杆」= 剔除客户资金后的自有资产杠杆
3. 判断：数值虽一致，但题干**偷换指标名称** → 陈述错误

### 建议结论

**gold = B（错误）**（倾向 Qwen verify，置信度高）

> 竞赛技巧：研报题对「除/不含/剔除」等限定词极其敏感，选项数字一致不代表陈述正确。

## 5. reg_a_012（监管 / 多选）— 优先级 80

关于上市公司治理及年度报告编制，以下说法符合规定的有哪些？

### 原文定位

| 选项 | 文档 | 位置 | 关键原文 |

## 6. ins_a_003（保险 / 单选）— 优先级 73

### 题干

李某投保了众安白血病医疗险、平安 e 生保（计划二，免赔额 5000 元）、太保团体百万医疗（免赔额 1 万元）。李某因白血病复发住院，总费用 8 万元，医保报销 3 万元，自费 5 万元。假设所有费用均属保险责任，众安白血病医疗险免赔额为 0，且为形态学复发。则三家保险公司共应赔付多少？

### 选项（注意陷阱）

| 选项 | 内容 |
|---|---|
| A | 众安 5 万 + 平安 4.5 万 + 太保 4 万 = **合计 13.5 万** |
| B | 同上（与 A 完全相同） |
| C | 同上（与 A 完全相同） |
| D | 无法确定，因众安免赔额和复发类型未知 |

### 原文定位

| 文档 | 位置 | 关键原文 |
|---|---|---|
| `5`（平安 e 生保） | 第 22 页 | 计划二免赔额 5000 元 |
| `5` | 第 4 页 | 医保补偿不可用于抵扣免赔额 |
| `6`（太保团体百万医疗） | 第 8 页 / 2.6 | **费用补偿原则**：「最高给付金额不超过被保险人实际发生的医疗费用扣除其所获医疗费用补偿后的余额」 |
| `3`（众安白血病） | 第 2–3 页 | 形态学复发可赔；第七条有免赔额/给付比例（题干已给定免赔额 0） |

### 分歧点

- **DeepSeek 选 D**：认为众安给付比例/免赔额证据不足
- **Qwen 选 A**：按分险种独立扣免赔额后加总得 13.5 万
- **Qwen verify 否定 A**：三份均为补偿型医疗险，总赔付不得超过自费 5 万，13.5 万违反补偿原则

### 正确计算逻辑

```
自费 = 8万 - 3万(医保) = 5万

补偿型原则：三家合计赔付上限 = 5万（不能各赔各的再相加）

朴素加总（错误）：
  众安: 5万 - 0 = 5万
  平安: 5万 - 0.5万 = 4.5万
  太保: 5万 - 1万 = 4万
  合计 13.5万 ← 违反补偿原则
```

### 核对步骤

1. 确认三份保单均为费用补偿型（doc `6` 2.6 明确；doc `3` 第七条亦有补偿说明）
2. 题干已给定「免赔额 0」「形态学复发」，D 的理由「未知」不成立
3. A/B/C 三者完全相同且数值错误 → 无正确数值选项
4. 在现有选项中，**排除法选 D** 最合理（承认简单加总不可行）

### 建议结论

**gold = D**（倾向补偿原则 + 排除法，置信度中等）

> 开放问题：若官方标准答案为 5 万，则本题选项设计可能有误（A/B/C 同值且超额）。建议竞赛主办方确认。
